# broadcastFrequency

The frequency used for over-the-air broadcasts. Numeric values or simple ranges, e.g. 87-99. In addition a shortcut idiom is supported for frequencies of AM and FM radio channels, e.g. "87 FM".

**Domain**: [BroadcastChannel](../classes/BroadcastChannel.md), [BroadcastService](../classes/BroadcastService.md)

**Range**: [BroadcastFrequencySpecification](../classes/BroadcastFrequencySpecification.md), [Text](../classes/Text.md)
