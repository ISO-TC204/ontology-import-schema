# merchantReturnDays

Specifies either a fixed return date or the number of days (from the delivery date) that a product can be returned. Used when the [[returnPolicyCategory]] property is specified as [[MerchantReturnFiniteReturnWindow]].

**Domain**: [MerchantReturnPolicy](../classes/MerchantReturnPolicy.md), [MerchantReturnPolicySeasonalOverride](../classes/MerchantReturnPolicySeasonalOverride.md)

**Range**: [Date](../classes/Date.md), [DateTime](../classes/DateTime.md), [Integer](../classes/Integer.md)

**IRI**: `http://schema.org/merchantReturnDays`
