# pagination

Any description of pages that is not separated into pageStart and pageEnd; for example, "1-6, 9, 55" or "10-12, 46-49".

**Domain**: [Article](../classes/Article.md), [Chapter](../classes/Chapter.md), [PublicationIssue](../classes/PublicationIssue.md), [PublicationVolume](../classes/PublicationVolume.md)

**Range**: [Text](../classes/Text.md)

**IRI**: `http://schema.org/pagination`
