# requiresSubscription

Indicates if use of the media require a subscription  (either paid or free). Allowed values are ```true``` or ```false``` (note that an earlier version had 'yes', 'no').

**Domain**: [ActionAccessSpecification](../classes/ActionAccessSpecification.md), [MediaObject](../classes/MediaObject.md)

**Range**: [Boolean](../classes/Boolean.md), [MediaSubscription](../classes/MediaSubscription.md)

**IRI**: `http://schema.org/requiresSubscription`
