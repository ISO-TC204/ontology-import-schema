# associatedDisease

Disease associated to this BioChemEntity. Such disease can be a MedicalCondition or a URL. If you want to add an evidence supporting the association, please use PropertyValue.

**Domain**: [BioChemEntity](../classes/BioChemEntity.md)

**Range**: [MedicalCondition](../classes/MedicalCondition.md), [PropertyValue](../classes/PropertyValue.md), [URL](../classes/URL.md)

**IRI**: `http://schema.org/associatedDisease`
