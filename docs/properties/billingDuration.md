# billingDuration

Specifies for how long this price (or price component) will be billed. Can be used, for example, to model the contractual duration of a subscription or payment plan. Type can be either a Duration or a Number (in which case the unit of measurement, for example month, is specified by the unitCode property).

**Domain**: [UnitPriceSpecification](../classes/UnitPriceSpecification.md)

**Range**: [Duration](../classes/Duration.md), [Number](../classes/Number.md), [QuantitativeValue](../classes/QuantitativeValue.md)

**IRI**: `http://schema.org/billingDuration`
