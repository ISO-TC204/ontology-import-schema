# unitCode

The unit of measurement given using the UN/CEFACT Common Code (3 characters) or a URL. Other codes than the UN/CEFACT Common Code may be used with a prefix followed by a colon.

**Domain**: [PropertyValue](../classes/PropertyValue.md), [QuantitativeValue](../classes/QuantitativeValue.md), [TypeAndQuantityNode](../classes/TypeAndQuantityNode.md), [UnitPriceSpecification](../classes/UnitPriceSpecification.md)

**Range**: [Text](../classes/Text.md), [URL](../classes/URL.md)

**IRI**: `http://schema.org/unitCode`
