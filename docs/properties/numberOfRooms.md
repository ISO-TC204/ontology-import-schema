# numberOfRooms

The number of rooms (excluding bathrooms and closets) of the accommodation or lodging business.
Typical unit code(s): ROM for room or C62 for no unit. The type of room can be put in the unitText property of the QuantitativeValue.

**Domain**: [Accommodation](../classes/Accommodation.md), [Apartment](../classes/Apartment.md), [FloorPlan](../classes/FloorPlan.md), [House](../classes/House.md), [LodgingBusiness](../classes/LodgingBusiness.md), [SingleFamilyResidence](../classes/SingleFamilyResidence.md), [Suite](../classes/Suite.md)

**Range**: [Number](../classes/Number.md), [QuantitativeValue](../classes/QuantitativeValue.md)
