# fuelType

The type of fuel suitable for the engine or engines of the vehicle. If the vehicle has only one engine, this property can be attached directly to the vehicle.

**Domain**: [EngineSpecification](../classes/EngineSpecification.md), [Vehicle](../classes/Vehicle.md)

**Range**: [QualitativeValue](../classes/QualitativeValue.md), [Text](../classes/Text.md), [URL](../classes/URL.md)

**IRI**: `http://schema.org/fuelType`
