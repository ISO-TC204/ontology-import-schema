# Schema.org Ontology

Schema.org is a collaborative, community activity with a mission to create, maintain, and promote schemas for structured data on the Internet.

NOTE: This ontology has been converted from Schema.org RDF/XML to Turtle for documentation generation with ont2md. Class declarations use owl:Class (instead of rdfs:Class) and properties use owl:ObjectProperty and/or owl:DatatypeProperty (instead of rdf:Property) based on schema:rangeIncludes. skos:definition annotations were added from rdfs:comment where missing. rdfs:subClassOf axioms were removed from enumeration individuals (e.g. MedicalSpecialty values) that Schema.org also marks as pseudo-classes, because ont2md documents only owl:Class terms and those individuals do not get pages. No other intentional semantic changes were made.
